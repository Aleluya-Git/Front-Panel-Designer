## Descargas / Downloads

| Sistema / System | Archivo / File |
|---|---|
| Windows 10/11 (64 bits) | `FrontPanelDesigner-…-Windows-x64-Setup.exe` |
| macOS Apple Silicon (M1–M4) | `FrontPanelDesigner-…-macOS-arm64.dmg` |
| macOS Intel | `FrontPanelDesigner-…-macOS-x86_64.dmg` |

**Windows** — ejecute el instalador. Como no está firmado digitalmente, SmartScreen puede avisar: pulse
«Más información» → «Ejecutar de todas formas». / Run the installer. It is not code-signed, so SmartScreen may
warn: click "More info" → "Run anyway".

**macOS** — abra el .dmg y arrastre la aplicación a Aplicaciones. No está firmada por Apple: la primera vez vaya
a Ajustes del Sistema → Privacidad y seguridad → «Abrir igualmente». / Open the .dmg and drag the app to
Applications. It is not notarized: the first time go to System Settings → Privacy & Security → "Open Anyway".

Linux y cualquier otro sistema: ejecútelo desde el código fuente (véase el README). / Linux and other systems: run
from source (see the README).
