## Español

**Windows** — ejecute el instalador. Como no está firmado digitalmente, SmartScreen puede avisar: pulse
«Más información» → «Ejecutar de todas formas».

**macOS** — abra el .dmg y arrastre la aplicación a Aplicaciones. No está firmada por Apple: la primera vez vaya a
Ajustes del Sistema → Privacidad y seguridad → «Abrir igualmente».

**Linux y otros sistemas** — ejecútelo desde el código fuente (véase el [README](https://github.com/Aleluya-Git/Front-Panel-Designer/blob/main/README.es.md)).

## English

**Windows** — run the installer. It is not code-signed, so SmartScreen may warn: click "More info" → "Run anyway".

**macOS** — open the .dmg and drag the app to Applications. It is not notarized by Apple: the first time go to
System Settings → Privacy & Security → "Open Anyway".

**Linux and other systems** — run it from source (see the [README](https://github.com/Aleluya-Git/Front-Panel-Designer/blob/main/README.md)).

## Deutsch

**Windows** — starten Sie das Installationsprogramm. Da es nicht digital signiert ist, kann SmartScreen warnen:
Klicken Sie auf „Weitere Informationen“ → „Trotzdem ausführen“.

**macOS** — öffnen Sie die .dmg-Datei und ziehen Sie die App in den Ordner „Programme“. Sie ist nicht von Apple
beglaubigt: Öffnen Sie beim ersten Start Systemeinstellungen → Datenschutz & Sicherheit → „Dennoch öffnen“.

**Linux und andere Systeme** — starten Sie das Programm aus dem Quellcode (siehe [README](https://github.com/Aleluya-Git/Front-Panel-Designer/blob/main/README.de.md)).

## Français

**Windows** — lancez l'installateur. Comme il n'est pas signé numériquement, SmartScreen peut afficher un
avertissement : cliquez sur « Informations complémentaires » → « Exécuter quand même ».

**macOS** — ouvrez le .dmg et faites glisser l'application dans Applications. Elle n'est pas notarisée par Apple :
au premier lancement, allez dans Réglages Système → Confidentialité et sécurité → « Ouvrir quand même ».

**Linux et autres systèmes** — lancez-le depuis le code source (voir le [README](https://github.com/Aleluya-Git/Front-Panel-Designer/blob/main/README.fr.md)).
